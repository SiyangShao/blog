我不知道我是看空还是看多，但我确实如下认为。不做任何价值观的判断，仅保存，以期在多年以后检查。
1. LLM 是未来。我相信 LLM 没有到头，不是泡沫。对 LLM 无论是市场还是未来都有充分的看好。
2. LLM 公司的护城河越来越窄了：
	1. Token 太具备可迁移性了。从一家迁移到另一家几乎不存在成本。这导致在满足能力的情况下，卷价格是唯一的出路
	2. 由此，中低端 LLM 无法卖出溢价。这个市场玩家太多了。从基模（MIMO / DeepSeek / Zai / Kimi / Qwen...）到推理公司（Together / Fireworks / SgLang / vLLM）。开源方案能达到闭源方案的80%。
	3. 高端 LLM 看不到护城河（或者说一家独大）的可能性。从 Fable 到 Kimi 到 GLM。在蒸馏技术始终存在的前提下，只要愿意，基模厂可以（虽然违背协议）的蒸馏一个还不错的版本。即使不考虑蒸馏，既然这么多厂商都能在某个时间点达到或达到过 SOTA，这只能说明这个行业不是造火箭。
3. 硬件公司不一定能笑到最后，但是 software-hardware co-design 能有效提升护城河
	1. 本质仍然是降本，卷成本和价格
	2. 可能并无法带来大家想象中的超额利润——取决于 hardware 和 asic 的护城河到底有多宽，以及 co-design 到底如何。
